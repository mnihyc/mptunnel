# Security policy

## Supported versions

Security fixes are applied to the latest published release and the default
branch. Older builds are unsupported.

## Reporting a vulnerability

Use **Security > Report a vulnerability** in the GitHub repository. This opens
a private report for the maintainers. Do not include exploit details, secrets,
or affected public endpoints in a public issue.

Include the affected version or commit, platform, configuration shape, expected
security boundary, observed behavior, and the smallest safe reproducer. Reports
about authentication, record protection, peer isolation, management access,
TUN routing, or resource exhaustion are in scope.

The MPP protocol and implementation have not received an independent security
audit. A successful build or performance result is not a security assurance.
